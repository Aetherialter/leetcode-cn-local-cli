v0.7.2 — 安全边界与诊断流程加固

v0.7.2 是安全性和可诊断性补丁版本，保持现有单题工作流不变。

### 修复

- `lc doctor` 默认不再执行 `solution.py`；需要执行解题文件时必须显式传入 `--run-solution`。
- 转义来自远端接口和本地文件的 Rich markup 与控制字符，避免终端显示内容注入。
- Cookie 域名改用标签边界匹配，不再接受仅以 `leetcode.cn` 结尾的非目标域名。
- 远端响应边界改用显式类型检查，确保在 Python 优化模式下仍返回结构化错误。
- 浏览器 Cookie 读取只忽略已知环境异常，使意外程序错误保留 traceback。
- 安装器不再自动下载和执行 uv 远端安装脚本；未检测到 uv 时仅提示官方文档。

### 文档

- 新增长期项目设计手册与源码安全审计清单。
- 明确当前单文件 `solution.py` 覆盖行为与链接目标风险的区别。

uv tool upgrade leetcode-local-cli
