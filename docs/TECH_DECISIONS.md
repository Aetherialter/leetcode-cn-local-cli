## 已废弃方案

### TD-006：直接读取浏览器 Cookie 数据库

状态：已废弃，由 TD-022 替代。

旧实现尝试使用 `browser-cookie3` 读取 Chrome Cookie，并以手动输入兜底。新版 Chrome 的应用绑定加密使普通进程无法稳定解密；继续自行解密会对抗浏览器安全边界。因此运行时代码和依赖均已删除，历史记录仅用于解释为什么改用用户显式授权的 DevTools。

同样废弃的实验路径包括 CLI 持有专用 Chrome profile 和旧参数 `--chrome-debug-port`。当前实现只复用用户日常 Chrome/Edge，不创建专用配置，也不关闭浏览器。
