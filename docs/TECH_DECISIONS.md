# 技术决策

只记录未来维护者可能重新讨论、且需要保留 Why/Trade-off 的选择。当前事实和待办分别归 `ARCHITECTURE.md` 与 `PROJECT_STATUS.md`。

| 决策 | Why / Trade-off |
| --- | --- |
| 使用 Python 3.12+、`src` 布局和 uv | 获得现代类型、隔离包和可复现工具链；wheel/sdist 仍必须支持普通安装。 |
| Typer/Rich 只留在 `cli.py` 与 `commands/` | 终端体验成熟，同时让应用流程可脱离 CLI 测试和复用；代价是显式适配层。 |
| `use_cases/` 编排，`models / storage / integrations / execution` 分层 | 原 `workspace.py` 混合文件、编辑器和进程职责，认证模块也混合浏览器与 Session；按实际资源边界拆分，使用 AST 约束依赖。代价是更多明确导入路径，内测不保留旧模块转发。 |
| 单默认工作区、单 `solution.py`、在线优先 | 心智模型和维护成本较低；不提供完整题库、离线归档或多工作区切换。 |
| 按生命周期拆分 `UserPaths`、`WorkspacePaths` 和组合型 `AppPaths` | 登录与账号查询不再被工作区配置绑住，需要两类资源的流程仍显式组合；代价是调用方要选择正确的路径上下文。 |
| Session 使用平台用户状态目录中的 JSON | 凭据属于系统用户而非题解工作区，切换工作区可保留登录态，也避免源码仓库和同步目录意外包含 Cookie；文件仍为明文，系统秘密存储留作后续强化。 |
| marker 使用 local-only 的 `.leetcode_local_cli/workspace.toml` | marker 只证明本机目录经过初始化，不提供跨机器共享价值；集中隐藏元数据可减少根目录噪音，但使用 Git 的工作区仍需用户自行忽略，CLI 不修改 `.gitignore`。 |
| 内测路径重构不兼容旧 Session 和 marker | 当前尚未形成稳定升级契约，直接删除旧状态并重新登录可避免复制凭据和长期兼容分支；代价是内测用户必须重新初始化和登录。 |
| 安全目标检查、同目录临时文件和原子替换 | 防止链接跟随、先截断和部分写入；非普通目标一律拒绝。 |
| Chrome/Edge 显式授权 DevTools 登录 | 由浏览器返回 Cookie，避免绕过浏览器加密；需要用户授权，授权期间端点权限较高。 |
| 持久独立 worker 执行 `lc test` | 可控制异常和超时并支持快速交互；它不是安全沙箱，也不能证明算法正确。 |
| 同步 `httpx.Client`，精确站点且拒绝全部重定向 | 当前请求量不值得引入 async；关闭自动跳转可避免泄漏 Cookie 或重放提交正文。即使同站跳转也拒绝，代价是接口迁移时必须显式更新代码。测试注入 transport，不替换生产安全配置。 |
| 提交使用总等待预算和结构化结果 | 固定次数无法约束真实耗时，裸字典与 `None` 也会丢失 submission ID；代价是增加结果模型与显式错误映射。POST 不重试，GET 只在预算内有限重试。 |
| 冻结 dataclass 与成功/失败联合类型 | 账号、题目分页和详情在 HTTP 边界完成类型转换；上层不认识传输字段，集合使用 tuple。账号聚合归用例，代价是新增模型及解析代码。 |
| Session 单次读取并统一校验 | 消除业务与 Doctor 两套校验和“检查后再次读取”的漂移；本地格式验证与在线身份验证仍是不同职责。模型默认 repr 隐藏 Cookie，但不替代秘密存储。 |
| 保存与打开分开计结果 | 文件保存是主操作，打开是可选后续动作。打开失败只警告且退出 0，用户可 `--no-open`；不把已落盘的成功误报为写入失败。 |
| 编辑器是可独立保存的用户设置，停用系统文件关联 | 工作区不应携带个人程序路径；`.py` 关联到 Python/uv 可能直接执行代码。显式程序加参数数组避免 Shell 解析，未配置只保存。代价是首次需要配置编辑器，且不保证启动请求对应可见窗口。 |
| 用户配置与 marker 独立版本化，只在显式写入时升级 | 编辑器表和可选工作区改变了用户配置契约，必须写为 v2，避免旧版误判为可修复的损坏；marker 保持 v1、Session 不变。现有 v1 配置只读可用，显式设置或初始化时写 v2；代价是升级后不能混用旧版配置命令，不引入自动磁盘迁移。 |
| 节点转换只由明确注解决定 | 数组不能靠参数名推断为链表或树；用受限 AST 识别字符串注解，避免额外执行注解表达式。采用力扣式数组输入输出并拒绝身份相关结构，代价是缺少注解需补齐，复杂节点题暂不覆盖。 |
| 复用节点模型源文件生成提交区域外的辅助定义 | 编辑器与本地 worker 使用相同结构，远端仍使用力扣节点环境；不在解法中导入 CLI 私有模块。代价是构建产物必须包含节点源码资源，由隔离 smoke test 覆盖。 |
| 异常行号默认显示、调用栈显式开启 | 默认输出易扫描，详细调试用 `test --verbose`，不采集局部变量；保留 JSON 协议结构及终端纯文本边界，但源码行和异常文本仍需用户检查后再共享。 |
| 显式 `init --repair`，先备份后写入 | 普通初始化不吞掉损坏配置；仅用户显式指定目标才恢复，保留原始字节和失败回滚。高版本或不支持站点优先拒绝，避免误覆盖新格式；不承诺断电时跨文件原子性。 |
| `UseCaseError.code` 与 CLI 退出码分离 | 用稳定类别支持机器消费，中文文案可以改写而不影响判断；运行错误退出 1，用法错误退出 2，`test --stdin` 启动错误保持 JSON。 |
| 日常 CI 与发布工作流分开 | push/PR 提前执行三平台 Python 3.12 门禁，标签发布仍使用既有流程；不引入账号或发布权限。版本声明仍为 3.12+，不声称所有更新小版本已验证。 |

## 已放弃方案

不再直接读取浏览器 Cookie 数据库：新版浏览器加密无法由普通进程稳定解密，继续尝试会对抗安全边界。旧 `browser-cookie3`、专用 Chrome profile 和固定 9222 启动方案已删除，当前统一使用用户显式授权的日常 Chrome/Edge DevTools。
